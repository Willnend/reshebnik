Политика конфиденциальности

Приложение «Решебник: Начальная школа»

1. Общие сведения

Приложение «Решебник: Начальная школа» (далее — «Приложение») предназначено для просмотра решебников (ГДЗ) по предметам начальной школы. Приложение работает полностью автономно (офлайн): все материалы — учебники, страницы, ответы и иллюстрации — находятся внутри самого приложения и не требуют подключения к интернету для работы.

2. Персональные данные

Приложение не собирает, не хранит и не передаёт никакие персональные данные пользователей:

  • не требует регистрации и создания учётной записи;
  • не запрашивает имя, возраст, телефон, адрес электронной почты или иные личные сведения;
  • не имеет доступа к контактам, фото, местоположению и другим данным устройства;
  • не отправляет какие-либо сведения на серверы разработчика.

3. Аналитика и трекеры

В Приложении отсутствуют системы аналитики, рекламные модули и трекеры. Поведение пользователей не отслеживается и не профилируется.

4. Покупки и подписки

Оформление покупок и подписок осуществляется исключительно через сервис «Плати с RuStore» (оператор — ООО «ВК»). Обработка платежей, управление подписками и связанные с ними данные (сведения о платежах, идентификатор покупателя) обрабатываются на стороне RuStore в соответствии с политикой конфиденциальности RuStore. Разработчик Приложения не получает и не хранит платёжные данные пользователей.

Политика конфиденциальности RuStore доступна на официальном сайте RuStore.

5. Дети

Приложение предназначено для использования при обучении в начальной школе и не содержит контента, недопустимого для детей. Поскольку Приложение не собирает данные, оно не создаёт рисков, связанных с обработкой данных несовершеннолетних.

6. Изменения политики

Разработчик может обновлять настоящую политику. Актуальная редакция всегда доступна на этой странице.
