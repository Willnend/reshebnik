# 📚 Локальный Решебник (ГДЗ) для Учителя — 1 класс

Автономная локальная программа с базой данных заданий, решений, пояснений и иллюстраций для 5 основных учебников 1 класса:

1. **Математика** (Моро М. И., Волкова С. И., Степанова С. В.) — 1 и 2 часть.
2. **Азбука** (Горецкий В. Г., Кирюшкин В. А., Виноградская Л. А.) — 1 и 2 часть.
3. **Русский язык** (Канакина В. П., Горецкий В. Г.) — 1 часть.
4. **Окружающий мир** (Плешаков А. А.) — 1 и 2 часть.
5. **Литературное чтение** (Климанова Л. Ф., Горецкий В. Г., Голованова М. В.) — 1 и 2 часть.

Всего в локальной базе: **887 страниц** и **711 иллюстраций схем и заданий**.

---

## 🚀 Быстрый запуск на компьютере (Windows)

Просто дважды кликните файл:
```
start_app.bat
```
Сервер запустится, в терминале отобразится адрес подключения, и в вашем браузере автоматически откроется решебник: `http://localhost:3000`.

---

## 📱 Как установить и использовать на iPad / iPhone

Благодаря поддержке стандарта **PWA (Progressive Web App)** приложение устанавливается на экран iPad / iPhone без App Store, без кабелей и без подписок:

1. Подключите iPad/iPhone к тому же Wi-Fi роутеру (или точке доступа), что и компьютер.
2. Откройте на iPad браузер **Safari** и перейдите по локальному адресу, который напечатан в окне сервера (например, `http://192.168.1.45:3000`).
3. Внизу (или вверху) Safari нажмите стандартную кнопку **«Поделиться»** (квадрат со стрелкой вверх).
4. Выберите пункт **«На экран «Домой»»** (Add to Home Screen) и подтвердите.
5. На рабочем столе iPad появится фирменная иконка **«Решебник 1 кл»**.
6. **Для полной автономности без интернета**: откройте приложение на iPad и в верхней панели нажмите кнопку **«📲 Скачать на iPad»**. Все 887 страниц и 711 картинок загрузятся в постоянную память планшета.
7. **Готово!** Теперь вы можете отключить Wi-Fi, выключить компьютер и открывать решебник прямо на уроке в школе — он будет работать **100% офлайн**.

## 🎓 Возможности для Учителя на уроке

* **Мгновенный переход по страницам**:
  * Прямой ввод номера страницы в шапке.
  * Кнопки «◀ Назад» и «Вперед ▶» (или клавиши стрелок на клавиатуре).
  * **Сенсорный Numpad**: при нажатии на номер страницы на iPad открывается крупная цифровая клавиатура для удобного набора одной рукой у доски.
* **Режим урока («Скрыть / Показать ответы»)**:
  * Кнопка со значком 🙈 размывает ответы и блок решений.
  * Учитель может вывести задание на проектор или спросить учеников, а затем одним нажатием (или клавишей `Пробел`) показать верный ответ.
* **Быстрый поиск по темам и тексту (`Ctrl+F`)**:
  * Введите тему (например: *«Один, два, три»*, *«Гласные звуки»*, *«Бусы»*, *«Живая природа»*) или номер страницы.
  * Поиск выдает подсказки с цитатами из задания и мгновенно переходит на нужный учебник и страницу.
* **Переключатель редакций учебника (2020 / 2023 год)**:
  * Если в школе используются разные издания учебников, прямо над заданием доступен переключатель годов.
* **Масштабирование текста (`🔠 Шрифт`)**:
  * Быстрое увеличение размера шрифта (4 уровня) для комфортного чтения с проектора или интерактивной доски.
* **Увеличение картинок (Lightbox)**:
  * Нажатие на любую картинку или схему открывает её в крупном размере на весь экран.

## 🧪 Запуск тестов

В проекте настроен автоматический тестовый контур:
```bash
npm test
```
Тесты проверяют:
1. Корректность парсинга HTML и разделения версий (2020 / 2023).
2. Целостность базы данных: наличие всех 887 страниц и 711 картинок на диске.
3. Доступность локального HTTP-сервера, API и PWA-манифеста.
