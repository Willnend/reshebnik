# 📚 Решебник 1 класс — ГДЗ для Учителя

Полноценный автономный решебник для 1 класса с базой данных материалов, заданий, пояснений, ответов и иллюстраций:
- **Математика** (Моро М. И., Волкова С. И., Степанова С. В.) — 1 и 2 часть.
- **Азбука** (Горецкий В. Г., Кирюшкин В. А., Виноградская Л. А.) — 1 и 2 часть.
- **Русский язык** (Канакина В. П., Горецкий В. Г.) — 1 часть.
- **Окружающий мир** (Плешаков А. А.) — 1 и 2 часть.
- **Литературное чтение** (Климанова Л. Ф., Горецкий В. Г., Голованова М. В.) — 1 и 2 часть.

Всего в базе: **887 страниц** и **711 иллюстраций схем и рисунков**.

## 💻 1. Установка и запуск на Windows

Собран полноценный нативный Windows-установщик (не батник, не веб-сервер в консоли):

* **Установщик (Setup Wizard)**:
  `dist\Решебник 1 класс Setup 1.0.0.exe`
  * Стандартный мастер установки Windows.
  * Создаёт ярлык на Рабочем столе и в Меню «Пуск».
  * Регистрирует программу в «Панели управления» / «Приложения и возможности» с возможностью чистого удаления.
* **Портативная версия (без установки)**:
  `dist\Решебник 1 класс 1.0.0.exe` (можно запускать с флешки).

### Как подписать вашим цифровым сертификатом (если требуется):
Если у вас есть сертификат `.pfx`, вы можете подписать файл установщика стандартной утилитой Windows `signtool.exe`:
```powershell
signtool sign /f "C:\path\to\cert.pfx" /p "ВАШ_ПАРОЛЬ" /tr http://timestamp.digicert.com /td sha256 /fd sha256 "dist\Решебник 1 класс Setup 1.0.0.exe"
```

## 🍏 2. Сборка для iOS (iPad / iPhone) через Codemagic и установка через Sideloadly

Проект полностью настроен для облачной сборки `.ipa` через сервис **Codemagic** (`https://codemagic.io`) и установки через провод программой **Sideloadly**:

### Шаг 1. Загрузка репозитория на GitHub
В папке проекта уже инициализирован git-репозиторий и сделан начальный коммит. Привяжите ваш GitHub:
```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
git branch -M main
git push -u origin main
```

### Шаг 2. Запуск сборки на Codemagic
1. Перейдите на [https://codemagic.io](https://codemagic.io) и войдите через GitHub.
2. Нажмите **«Add application»** и выберите ваш созданный репозиторий.
3. Выберите тип конфигурации **«Codemagic configuration file»** (файл `codemagic.yaml` уже лежит в корне репозитория).
4. Нажмите **«Start new build»** и выберите воркфлоу `ios-release`.
5. Codemagic запустит виртуальную машину macOS, скомпилирует Xcode-проект и сформирует готовый файл:
   `Reshebnik_1klass.ipa`
6. Скачайте полученный `.ipa` из раздела **Artifacts**.

### Шаг 3. Установка на iPad / iPhone через Sideloadly
1. Подключите iPad или iPhone к компьютеру через USB-кабель.
2. Откройте программу **Sideloadly** на компьютере.
3. Перетащите скачанный `Reshebnik_1klass.ipa` в окно Sideloadly.
4. Введите ваш Apple ID и нажмите кнопку **«Start»**.
5. Программа подпишет приложение и установит его прямо на планшет.
6. На iPad перейдите: **Настройки → Основные → VPN и управление устройством**, нажмите на ваш Apple ID и выберите **«Доверять»**.
7. Приложение готово к работе! Все 887 страниц и 711 картинок находятся внутри бандла, поэтому приложение на iPad открывается мгновенно и работает **100% офлайн без интернета**.

## 🎓 Возможности для Учителя на уроке

* **Мгновенный переход к странице**:
  * Прямой ввод номера в шапке.
  * Кнопки «◀» и «▶» (или стрелки клавиатуры).
  * **Сенсорный Numpad**: при нажатии на номер страницы на iPad открывается крупный блок цифр для набора одной рукой.
* **Режим урока («🙈 Скрыть ответы»)**:
  * Возможность скрыть ответы (размытие блока решений), чтобы спросить учеников или спроецировать задание, а затем в один клик (или по клавише `Пробел`) показать решение.
* **Быстрый поиск по темам и тексту (`Ctrl+F`)**:
  * Мгновенный поиск по темам (напр. *«Гласные звуки»*, *«Живая природа»*, *«Один, два, три»*) и цитатам.
* **Переключатель редакций учебников (2020 / 2023)** прямо над заданием.
* **Шрифт для проектора (`🔠 Шрифт`)**: 4 уровня увеличения текста.
* **Увеличение картинок**: клик по любой схеме открывает её в полноэкранном режиме.
